EQUANS Firebase Setup V1

Separate Setup-Datei. Sie verändert nicht die Rapport-HTML und löscht keine alten Collections.

Projekt: equans-rapport-test Admin: Danuwat Latthiwan

1. Admin anmelden

Nicht angemeldet.

2. Firebase prüfen

Prüft users, alte orders/auftragTest und vorhandene V1-Basis. Es wird noch nichts geschrieben.

3. V1-Basis erstellen / reparieren

Sicherheitsregel: users, orders, auftragTest und vorhandene Rapporte werden nicht gelöscht. Bestehende V1-Dokumente werden nur mit fehlenden Basisfeldern ergänzt; Versionsstände werden nicht künstlich hochgezählt.

Was angelegt wird

admin/system
  masterData        ← EIN festes Dokument
    version
    updatedAt
    auftraege[]

config/system       ← EIN festes Dokument
  schemaVersion
  updatedAt

monteure/{UID}/sync/data
  version           ← EIN festes Dokument je Benutzer
  updatedAt

monteure/{UID}/meta/profile
  displayName
  username
  role
  active

Später durch Rapport-App:
monteure/{UID}/rapporte/{RPT-ID}

Admin-Konflikte/Audit werden erst bei tatsächlichen
Ereignissen als Dokumente erzeugt – keine Dummy-Dokumente.
